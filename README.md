🐍 Exercícios de Python: Curso em Vídeo

Professor: Gustavo Guanabara

Este repositório contém as minhas resoluções para os desafios do curso de Python. O objetivo é documentar a minha evolução, desde a instalação da linguagem até à criação de algoritmos complexos de automação e lógica.

🚀 O que aprendi até agora:

🌍 Mundo 1: Fundamentos 

Tratamento de Dados: Tipos primitivos (int, float, bool, str).

Operações Aritméticas: Cálculos e a biblioteca math.

Módulos: Importação de ferramentas externas.

Manipulação de Texto: Análise e fatiamento de strings.

Estruturas de Controlo: Decisões simples com if e else.

Estética: Cores no terminal com códigos ANSI.

🌌 Mundo 2: Estruturas de Controlo (Em andamento...) 

Condições Aninhadas: Uso de elif para decisões múltiplas e complexas.

Repetições com for: Laços com limites definidos (Iteração).

Repetições com while: Laços com interrupções lógicas e uso de flags.

Lógica Avançada: Criação de menus interativos, validação de dados e sequências matemáticas (como Fibonacci e Progressões Aritméticas).
